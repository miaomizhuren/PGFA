# Perturbation-metric provenance

## Publicly released evidence

`results/perturbation/formal_perturbation_audit.csv` is an evidence-indexed table, not a new evaluation.  Its CE-only UAP, DBA, and PGFA rows are copied directly from the original read-only offline audit record at `SOURCE_ROOT/outputs/final_trigger_stealth_audit_20260924/trigger_stealth_persistence_summary.csv`; the exact row selector is in the table.  That source reports the paper-adopted values: CE-only 32.4874 / 0.955413 / 0.026160, DBA 16.9716 / 0.932414 / 1.000000, and PGFA 32.4773 / 0.955128 / 0.026160 (PSNR / SSIM / raw L-infinity).

For formal **A3FL-v2-Relaxed-Strong**, the adopted value is taken directly from `results/a3fl_formal/08_relaxed_strong_all_700_rounds.csv`, row R3200: 27.854146 / 0.912523 / 0.047088.  No separate fixed-1,000-image offline audit artifact for this Relaxed-Strong checkpoint was found.  The public table therefore labels this row as `formal_R3200_saved_roundwise_metric` rather than implying that it was generated by the CE/DBA/PGFA offline audit.

## Why the values differ from the roundwise snapshot

`roundwise_metric_snapshot_R3200.csv` preserves the existing online values from the formal SQLite exports and is deliberately labeled `online_roundwise_metric_snapshot`.  The online server calls `evaluation/evaluator.py::compute_stealth_metrics` on its cached deterministic test batch and computes PSNR once from the batch-wide MSE, then averages per-image SSIM.

The original offline audit was produced by `SOURCE_ROOT/scripts/audit_trigger_stealth_and_persistence.py`.  It selects 1,000 non-target CIFAR-10 test images with NumPy seed 20260924, applies the final R3200 trigger in raw RGB after inverse normalization and clipping, computes PSNR per image and then averages it, computes per-image SSIM (`skimage.metrics.structural_similarity`, `channel_axis=-1`, `data_range=1`), and takes global raw L-infinity.  The differing image subset and PSNR aggregation explain the CE/DBA/PGFA differences; neither record has been altered.

The original offline audit's A3FL row is a historical non-Relaxed-Strong variant and is intentionally not included in this release.  The four-row public table above instead uses the verified Relaxed-Strong R3200 source for A3FL.

## Re-execution boundary

The original offline audit requires the excluded CIFAR-10 dataset and saved `delta_round_3200.pt` trigger files.  They are not included in the public release, so this repository preserves the evidence and method description but does not claim a self-contained rerun of that offline audit.
